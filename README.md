# hacktivity-stats
Dashboard to give a informative summary and stats from hackerone's recent disclosed hacktivity

## To build
1. Add a `.env` file with your Hackerone username and password in the outermost directory
```
H1_USERNAME=your_username_here
H1_TOKEN=your_token_here
```
2. Add firebase_config.json in backend/
3. Run these commands in cmd
```cmd
npm i
npm run dev
```
